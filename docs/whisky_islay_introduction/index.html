アイラウイスキー入門

スコットランドの西の海に浮かぶアイラ島は、スモーキーで個性の強いウイスキーの産地として知られる。本書は、ウイスキーの基礎から始めて、アイラ島という土地、歴史、ピートとスモーキーさの仕組み、各蒸留所の個性、そして飲み方と選び方までを順に解説する。
