12. 自家製の茶外茶

茶外茶の中には、家庭で手軽に作れるものも多い。この章では、麦茶、ハーブティー、野草茶を自分で作る方法と、安全上の注意を説明する。

12.1. 麦茶を大麦から作る

麦茶は、殻付きの大麦をフライパンで焙煎して作ることができる。殻付きの大麦は、通信販売や農産物の直売所などで手に入る。精麦した押し麦（ご飯に混ぜる大麦）でも作れるが、殻付きのものに比べて香ばしさが弱く、焦げやすい。

  1. 殻付きの大麦を、ざるに入れて水で軽く洗い、水気をよく切ってから広げて乾かす。

  2. フライパンに大麦を入れ、中火にかける。油はひかない。

  3. フライパンを揺すったり、木べらで混ぜたりしながら、焦がさないように 15〜20 分ほど炒る。

  4. 大麦が濃い茶色になり、香ばしい香りが出てきたら火を止める。

  5. 皿などに広げて冷まし、完全に冷めたら密閉容器に入れて保存する。

焙煎の時間が短いと色の薄いさっぱりした麦茶に、長いと色の濃い香ばしい麦茶になる。淹れ方は、市販の麦茶と同じである（9 章を参照）。

12.2. ハーブを育てて乾燥させる

ミント、レモンバーム、カモミール、レモングラスなどのハーブは、ベランダの鉢植えでも育てやすい。特にミントは丈夫で、よく増える。地植えにするとほかの植物の場所まで広がることがあるため、鉢植えで育てるとよい。

育てたハーブは、摘みたての生の葉で淹れることもできる。生の葉で淹れる場合は、乾燥した葉の 3 倍程度の量を目安にする。

保存する場合は、次の手順で乾燥させる。

  1. 晴れた日の午前中に、葉や花を摘み取る。

  2. 汚れを水で軽く洗い、水気をよく拭き取る。

  3. 枝ごと数本ずつ束ね、風通しのよい日陰につるすか、ざるに広げて乾燥させる。直射日光に当てると、色や香りが落ちやすい。

  4. 葉が指でつまんで砕けるくらいまで乾いたら、密閉容器に入れて保存する。

12.3. 野草茶を作る

どくだみや柿の葉など、身近な植物から野草茶を作ることもできる。

12.3.1. どくだみ茶

  1. 花が咲く初夏（5〜6 月ごろ）に、地上に出ている部分を根元から刈り取る。

  2. 水でよく洗って土や汚れを落とし、束ねて風通しのよい日陰につるす。

  3. 1〜2 週間ほどで、葉がからからに乾いたら、適当な長さに切って密閉容器に入れる。

乾燥させると、生のときの強いにおいが弱くなる。

12.3.2. 柿の葉茶

  1. 初夏（5〜6 月ごろ）に、柔らかい若葉を摘む。

  2. 水で洗い、葉の中心にある太い葉脈を取り除いて、細かく刻む。

  3. 刻んだ葉を 1〜2 分ほど蒸す。

  4. ざるに広げて、風通しのよい日陰で乾燥させる。

  5. よく乾いたら、密閉容器に入れて保存する。

12.4. 安全上の注意

自分で植物を採って茶外茶を作る場合は、次の点に十分注意する。

  • 確実に見分けられる植物だけを使う：食べられる植物とよく似た毒のある植物があり、間違えて食べたことによる食中毒が毎年起きている。少しでも自信がない植物は、採らない、使わない。

  • 採る場所に注意する：道路沿い（排気ガス）、農薬や除草剤がまかれている可能性がある場所、犬の散歩道などで採った植物は使わない。他人の土地や、植物の採取が禁止されている場所では採らない。

  • 観賞用の植物を使わない：園芸店で観賞用として売られている植物には、食用を想定していない農薬が使われていることがある。茶外茶に使う植物は、食用の苗や種から育てる。

  • よく乾燥させる：乾燥が不十分だと、保存中にカビが生えることがある。カビが生えたものは使わない。

  • 少量から試す：初めて飲む植物は、少量から試し、体調に異変を感じたら飲むのをやめる。
